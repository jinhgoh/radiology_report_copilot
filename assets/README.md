# App icon

`app-icon.png` was created with the built-in image generation tool. It depicts a stylized X-ray ribcage and mint heart on a deep teal tile. `scripts/build-icon.ps1` packages the artwork into `RadiologyReportCopilot.ico` at 16, 20, 24, 32, 40, 48, 64, 128, and 256 pixels.

Generation prompt:

> Use case: logo-brand. Asset type: a single Windows desktop application icon for Radiology Report Copilot, a veterinary radiology reporting program with canine/feline echocardiography. Create a polished, simple, immediately legible radiology emblem: a dark deep-teal rounded-square tile with a bold luminous ivory/cyan stylized X-ray ribcage, and a small solid mint heart at its center. The ribs are a minimal symmetrical pictogram, just three broad curved pairs and one central spine, not realistic anatomy. Flat vector-like graphic, strong clean geometry, restrained subtle teal shading, thick shapes readable at 32px, professional medical software aesthetic. Square 1024x1024 composition, one icon centered and filling 90% of the canvas. Actual transparent alpha background outside the tile with crisp rounded corners. No words, letters, numbers, watermark, mockup, extra badges, paw prints, or surrounding decorations. Deliver a single finished icon image.
